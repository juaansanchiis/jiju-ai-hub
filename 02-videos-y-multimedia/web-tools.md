# Vídeos y multimedia

Herramientas web y plugins para creación multimedia con tiers gratuitos potentes.

## Herramientas de vídeo/audio con tiers gratuitos potentes

- **ElevenLabs:** Generación de voces y efectos de sonido con los créditos gratuitos mensuales. Ideal para voiceovers y SFX.
- **Runway (Gen-2 / Gen-3) o Luma Dream Machine:** Generación de vídeo por IA con pruebas gratuitas.
- **Kling AI / Pika:** Alternativas punteras para creación multimedia rápida.
- **Suno / Udio:** Creación de canciones y sintonías (intros, proyectos, etc.) con sus versiones gratuitas.
- **CapCut Web:** Funciones automáticas de subtitulado y edición impulsadas por IA.
