## Enlaces rápidos a proveedores gratuitos favoritos

- [OpenRouter](https://openrouter.ai/) — Modelos `:free` para desarrollo y testing sin coste.
- [Google AI Studio (Gemini)](https://aistudio.google.com/) — API de Gemini con tier gratuito.
- [Groq](https://groq.com/) — Inferencia ultra rápida con límites de tasa altos.
- [Mistral](https://mistral.ai/) — Endpoints gratuitos para pruebas.
- [Cohere](https://cohere.com/) — Tier gratuito para experimentación.
- [Hugging Face](https://huggingface.co/) — Inference API / Serverless para modelos open-source.

## Estándares y formato de documentación

Cada herramienta se documenta siguiendo este formato mínimo:

- **Nombre** de la herramienta o proveedor.
- **Tipo** (API, herramienta web, plugin, agente, framework, app de escritorio, etc.).
- **Enlace** oficial o repositorio.
- **Descripción** breve de qué hace y para qué sirve.
- **Notas** con límites, costes, configuración relevante o advertencias.

Las tablas Markdown son el formato preferido para listados comparativos. Los snippets de código usan bloques con lenguaje (`bash`, `python`, `json`, etc.). Los comandos de instalación y configuración se incluyen siempre que sea posible.
