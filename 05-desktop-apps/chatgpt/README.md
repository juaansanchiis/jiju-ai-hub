# ChatGPT (app de escritorio)

Trucos de la app de escritorio de ChatGPT, atajos de teclado y configuración general.

## Atajos de teclado

- `Ctrl/Cmd + Shift + O` — Nueva conversación.
- `Ctrl/Cmd + /` — Mostrar atajos.
- `Ctrl/Cmd + Shift + C` — Copiar último mensaje.

## Configuración general

- Activa "Modo desarrollador" para herramientas avanzadas.
- Configura el modelo por defecto (GPT-4o, o1, etc.) según la tarea.
- Usa proyectos para organizar conversaciones por tema.
