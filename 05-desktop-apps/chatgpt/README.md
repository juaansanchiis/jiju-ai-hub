# ChatGPT (app de escritorio)

Trucos de la app de escritorio de ChatGPT, atajos de teclado y configuración general.

## Instalación

Descarga desde [openai.com/chatgpt/desktop](https://openai.com/chatgpt/desktop/) (Windows/macOS).

## Atajos de teclado

- `Ctrl/Cmd + Shift + O` — Nueva conversación.
- `Ctrl/Cmd + /` — Mostrar atajos.
- `Ctrl/Cmd + Shift + C` — Copiar último mensaje.
- `Ctrl/Cmd + K` — Búsqueda rápida.
- `Ctrl/Cmd + Shift + ;` — Captura de pantalla para análisis.

## Configuración general

- Activa "Modo desarrollador" para herramientas avanzadas.
- Configura el modelo por defecto (GPT-4o, o1, etc.) según la tarea.
- Usa proyectos para organizar conversaciones por tema.
- Activa la memoria para personalización persistente.

## Modelos disponibles

- **GPT-4o:** Multimodal, rápido, buen balance.
- **o1 / o1-mini:** Razonamiento avanzado (más lento, más caro).
- **GPT-4o-mini:** Económico para tareas simples.

## Buenas prácticas

- Usa proyectos para separar contextos (trabajo, personal, etc.).
- Activa la memoria solo si quieres personalización.
- Revisa las Actions antes de ejecutarlas.
- Usa Custom GPTs para tareas repetitivas.

## Solución de problemas

- **App no arranca:** reinstala o borra caché en `%APPDATA%\ChatGPT`.
- **Modelo no disponible:** verifica tu plan (Plus/Pro).
- **Conectores fallan:** revisa permisos y HTTPS.
