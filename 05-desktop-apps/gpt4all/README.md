# GPT4All

Cliente de escritorio para modelos locales con RAG integrado. Ideal para usuarios no técnicos.

## Instalación

Descarga desde [gpt4all.io](https://gpt4all.io/) (Windows/macOS/Linux).

## Características

- Chat con modelos locales (Llama, Mistral, etc.).
- Descarga de modelos desde el hub integrado.
- RAG integrado (importar documentos locales).
- Sin telemetría, privacidad total.
- Interfaz simple y amigable.
- Soporte de GPU (opcional).

## Uso básico

1. Abre GPT4All.
2. Descarga un modelo desde "Models".
3. Inicia un chat.
4. (Opcional) Importa documentos para RAG.

## Modelos disponibles

- Llama 3, Mistral, Phi, etc.
- Modelos optimizados para CPU (no requiere GPU).

## RAG (Retrieval-Augmented Generation)

1. Ve a "LocalDocs".
2. Añade una carpeta con documentos (PDF, TXT, MD).
3. GPT4All indexará los documentos.
4. En el chat, activa "LocalDocs" para consultar tus documentos.

## Buenas prácticas

- Usa modelos optimizados para CPU si no tienes GPU.
- Limita el tamaño de los documentos para RAG.
- Mantén GPT4All actualizado.

## Solución de problemas

- **Modelo no descarga:** verifica la conexión a internet.
- **RAG no funciona:** verifica que los documentos estén en formatos soportados.
- **Lento:** usa un modelo más pequeño o reduce el contexto.

## Notas

- Gratuito y open-source.
- Ideal para usuarios no técnicos.
- Enfoque en privacidad (todo local).
- No requiere GPU (funciona en CPU).
